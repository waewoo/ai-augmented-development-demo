# Répertoire des Plans & Traçabilité (`plans/`)

Ce répertoire regroupe les artefacts de cadrage, de suivi et de contrôle générés par les skills de l'agent :

| Fichier | Skill associé | Rôle & Contenu |
| :--- | :--- | :--- |
| **`plans/PLAN.md`** | `plan-change` | Plan de cadrage initial, critères d'acceptation, fichiers cibles, tests prévus, risques et checklist d'étapes. |
| **`plans/AVANCEMENT.md`** | `implement-change` | Journal de bord de l'implémentation, cases cochées (`- [x]`), commandes exécutées et preuves déterministes. |
| **`plans/REVIEW.md`** | `review-change` | Rapport d'audit de conformité, grille de sévérité, comparaison au plan et verdict de fusion. |

> 💡 **Accès rapide :** Chaque fichier est directement cliquable depuis la conversation de l'agent (Kilo Code) pour une consultation immédiate dans l'éditeur.
